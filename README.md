# Healthcare Appointment & Patient Portal

A responsive front-end web application designed to provide a simple interface for patient registration, appointment management, and health information.

## Project Overview

The Healthcare Appointment & Patient Portal is a responsive web-based application developed using HTML5, CSS3, and Bootstrap 5.

The project provides a structured interface where patients can enter their personal information, select a department and doctor, schedule an appointment, and view appointment and health information.

The interface is designed to work across different screen sizes using responsive design techniques.

---

## Project Objective

The main objective of this project is to develop a responsive healthcare portal that provides:

- Patient registration
- Doctor and department selection
- Appointment scheduling
- Appointment information display
- Patient health information
- Healthcare services information
- Responsive navigation and user interface

---

## Development Process

### 1. Website Structure

The basic structure of the application was created using HTML5.

The website was divided into different sections:

- Home
- Patient Registration
- Appointments
- Health Information
- Services
- Technologies

### 2. Navigation Bar

A responsive navigation bar was created using Bootstrap 5.

It provides links to the main sections of the portal and allows users to move between different parts of the website.

### 3. Patient Registration Form

A registration form was developed to collect patient information such as:

- Patient Name
- Email
- Mobile Number
- Date of Birth
- Gender
- Blood Group
- Department
- Doctor
- Appointment Date
- Appointment Time
- Address
- Symptoms / Health Concern

HTML5 form validation was used for the required fields.

### 4. Appointment Management

An appointment table was created to display:

- Appointment ID
- Patient Name
- Department
- Doctor
- Appointment Date
- Appointment Time
- Appointment Status

JavaScript was used to add newly registered appointment information dynamically to the table.

### 5. Health Information

A separate Health Information section was created to display important patient and appointment details, including:

- Patient Name
- Blood Group
- Department
- Doctor
- Appointment Date
- Appointment Time
- Symptoms
- Appointment Status

### 6. Services Section

A Services section was added to present the main healthcare services provided by the portal, including doctor consultation, appointment management, and health information.

### 7. Technologies Section

The project includes a dedicated section displaying the technologies used to develop the application.

### 8. CSS Styling

CSS3 was used to improve the appearance of the application, including:

- Layout styling
- Typography
- Cards
- Buttons
- Forms
- Tables
- Spacing
- Responsive adjustments

### 9. Responsive Design

Bootstrap 5 grid classes and CSS media queries were used to make the portal responsive.

The interface adjusts its layout for desktop, tablet, and mobile screen sizes.

### 10. JavaScript Functionality

JavaScript DOM manipulation was implemented to handle patient registration.

When a patient submits the registration form:

1. Form values are collected.
2. An appointment ID is generated.
3. The appointment is added to the appointment table.
4. Health information is updated.
5. A registration confirmation message is displayed.

### 11. Testing

The application was tested by:

- Opening the website using a local development server.
- Testing the patient registration form.
- Checking form validation.
- Testing appointment creation.
- Checking the health information section.
- Testing the navigation links.
- Checking the responsive layout on different screen sizes.

### 12. Version Control

Git was used for version control.

The project was initialized as a Git repository, the source files were committed, and the project was pushed to GitHub.

### 13. Deployment

The project was deployed using GitHub Pages.

The final website is publicly accessible through the Live Demo link provided above.
